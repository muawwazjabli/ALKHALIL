# الخلیل پبلشرز (Al Khalil Publishers) — ای کامرس ویب سائٹ و اشاعتی پورٹل

ایک مکمل، پروڈکشن ریڈی اور جدید اسلامی آن لائن بک اسٹور اور پبلشنگ ہاؤس ای کامرس ویب سائٹ برائے **الخلیل پبلشرز (Al Khalil Publishers)**۔

---

## 🌟 اہم خصوصیات (Key Features)

### 1. خوبصورت اور مستند پبلک اسٹور فرنٹ (Public Storefront)
- **مکمل اردو RTL سپورٹ**: نفیس نستعلیق و نسخ فونٹس (`Noto Nastaliq Urdu`, `Noto Sans Arabic`, `Tajawal`) کے ساتھ اعلیٰ معیار کی طباعتی ڈیزائن۔
- **رنگوں کا امتزاج**: مڈ نائٹ نیوی بلیو (`#0B132B`)، وارم میٹ گولڈ (`#C5A059`)، اور آف وائٹ/آئیوری (`#FCFBF7`)۔
- **صفحہ اول (Homepage)**: شاہکار کتب، تازہ ترین مطبوعات، زیادہ فروخت ہونے والی کتب، خصوصی رعایتیں اور منتخب ناشرین و مصنفین کی فہرست۔
- **کتب خانہ و زمرہ جات (Catalog & Categories)**: عنوان، مصنف، ناشر کی تلاش، ترتیب بلحاظ قیمت و مقبولیت، اور دستیاب کتب کے فلٹرز۔
- **کتاب کا تفصیلی صفحہ (Book Details)**:
  - سرورق، تصویری گیلری اور مکمل بائنڈنگ، جلدیں، صفحات، وزن، شمارہ، اور تفصیلی جائزہ۔
  - **ملٹی پبلشر اور ملٹی ایڈیشنز سلیکٹر**: ایک ہی کتاب کے مختلف اشاعتی اداروں کے ایڈیشنز (الخلیل پبلشرز، دار العلوم کراچی، مکتبۃ البشریٰ، دار السلام) کے انفرادی نرخ، رعایت، وزن اور اسٹاک اسٹیٹس۔
- **خریداری کی ٹوکری (Shopping Cart)**: خودکار حساب کتاب، اسٹاک ویلیڈیشن، وزن کی پیمائش، پرومو کوڈز۔
- **چیک آؤٹ (Multi-step Checkout)**: گاہک کے کوائف، پاکستان کے تمام صوبوں و شہروں کے لیے وزن کے مطابق خودکار کوریئر چارجز کا حساب، اور پیمنٹ سلیکشن۔
- **رسید و انوائس (Invoice & Printable Receipt)**: مکمل پرنٹ فرینڈلی انوائس اور ایک کلک پر واٹس ایپ کے ذریعے آرڈر کی تفصیلات ارسال کرنے کی سہولت۔
- **صارف اکاؤنٹ و ٹریکنگ (Customer Tracking)**: آرڈر موصول → تصدیق شدہ → پیکنگ جاری → روانہ شدہ → پہنچ گیا کا بصری پروگریس ٹریکر اور ادائیگی کی رسید اپلوڈ کرنے کا فارم۔

### 2. طاقتور اور محفوظ ایڈمن پورٹل (`/admin`)
- **کردار پر مبنی رسائی (RBAC)**: Super Admin, Inventory Manager, Order Manager.
- **ڈیش بورڈ (Dashboard)**: مجموعی فروخت، روزانہ کے آرڈرز، ترسیلی کیفیت کے گراف، کم اسٹاک و ختم اسٹاک الرٹس۔
- **کتب و ایڈیشنز مینجمنٹ (Book Management)**:
  - مکمل کتاب کا اندراج، متعدد ناشرین، جلدیں، لاگتِ خرید (Purchase Cost)، فروخت کی قیمت اور رعایتی قیمت کا خودکار فارمولا:
    $$\text{Final Price} = \text{Regular Price} - \left(\frac{\text{Regular Price} \times \text{Discount Percentage}}{100}\right)$$
  - ایڈیشن فارم کے دوران ہی فوری طور پر نیا ناشر شامل کرنے کی سہولت۔
- **اسٹاک و انوینٹری کنٹرول (Inventory & Audit Trail)**: ہر ایڈیشن کا موجودہ اسٹاک، کم اسٹاک کی حد، دستی ایڈجسٹمنٹ (نیا اسٹاک موصول، ضائع شدہ کتب، درستگی شمار، واپسی) اور مکمل آڈٹ لاگ۔
- **آرڈرز مینجمنٹ (Order Fulfillment Workflow)**:
  - منتظرِ ادائیگی → ادائیگی تصدیق شدہ → پیکنگ جاری → روانہ شدہ → پہنچ گیا۔
  - منسوخ ہونے پر اسٹاک کی خودکار بحالی (Auto stock restoration on cancellation)۔
  - کوریئر کا نام، ٹریکنگ نمبر اور اسٹاف کے نوٹس کے ساتھ آڈٹ تاریخچہ۔
- **شپنگ چارجز کا نظام (Dynamic Shipping Rules)**: صوبائی اور شہر کے لحاظ سے بنیادی کرایہ، شامل وزن (گرام) اور اضافی فی کلو ریٹ، مع مفت ترسیل کی حد۔
- **پرومو کوڈز انجن (Promo Codes)**: فیصدی یا فکسڈ رعایت، کم از کم آرڈر حد، زیادہ سے زیادہ رعایت کی حد اور استعمال کے کاؤنٹرز۔
- **کاروباری رپورٹس (Financial Reports & CSV Export)**: فروخت، لاگت، مجموعی منافع مارجن (Gross Profit Margin)، گودام انوینٹری کی موجودہ مالیت، اور ایک کلک پر CSV رپورٹ ایکسپورٹ۔
- **اسٹور سیٹنگز (Store Settings)**: نام، واٹس ایپ نمبر، بینک اکاؤنٹ، ایزی پیسہ، جاز کیش اکاؤنٹس کا انتظام۔

## 🛠️ ٹیکنالوجی اسٹیک (Tech Stack)

- **Frontend & Server**: [Next.js](https://nextjs.org/) (App Router), React 18, TypeScript.
- **Styling**: Tailwind CSS, RTL layout support, Lucide React icons.
- **Database & Storage**: [Supabase](https://supabase.com/) (PostgreSQL 14+), Row Level Security (RLS), Storage Buckets.
- **Automated Testing**: [Vitest](https://vitest.dev/) (Financial calculations, shipping increments, promo validation).

## 🚀 مقامی سیٹ اپ و تنصیب (Local Setup)

### 1. ریپوزٹری کلون کریں
```bash
git clone https://github.com/your-username/al-khalil-publishers.git
cd al-khalil-publishers
```

### 2. انحصار کی تنصیب (Install Dependencies)
```bash
npm install
```

### 3. ماحولیاتی متغیرات (Environment Variables)
`.env.example` کو `.env.local` میں کاپی کریں اور اپنی Supabase کی معلومات درج کریں:
```bash
cp .env.example .env.local
```

فائل `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key

NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_DEFAULT_WHATSAPP=923001234567
NEXT_PUBLIC_STORE_NAME_UR=الخلیل پبلشرز
NEXT_PUBLIC_STORE_NAME_EN=Al Khalil Publishers
```

### 4. ڈیٹا بیس مائیگریشنز چلائیں (Database Migrations)
1. Supabase ڈیش بورڈ پر نیا پراجیکٹ بنائیں۔
2. **SQL Editor** کھولیں۔
3. فائل `supabase/migrations/20261025000000_init_al_khalil_schema.sql` کا مواد پیسٹ کر کے Run کریں۔
4. فائل `supabase/migrations/20261025000001_seed_and_functions.sql` کا مواد پیسٹ کر کے Run کریں۔
5. آپ کے پاس تمام 24 ٹیبلز، RLS سیکیورٹی پالیسیاں، اسٹورڈ پروسیجرز اور اسلامی کتب و ناشرین کا سیڈ ڈیٹا تیار ہو جائے گا۔

### 5. ٹیسٹنگ اور لوکل سرور چلائیں
```bash
# خودکار حسابی ٹیسٹ چلائیں
npm test

# ڈویلپمنٹ سرور چلائیں
npm run dev
```
ویب سائٹ `http://localhost:3000` پر اور ایڈمن پورٹل `http://localhost:3000/admin` پر دستیاب ہوگا۔

## ☁️ Vercel پر تعیناتی (Deployment to Vercel)

1. اپنا کوڈ GitHub پر پش کریں:
   ```bash
   git add .
   git commit -m "Production release: Al Khalil Publishers complete platform"
   git push origin main
   ```
2. [Vercel](https://vercel.com/) پر جا کر **Add New Project** منتخب کریں اور اپنی GitHub ریپوزٹری امپورٹ کریں۔
3. **Environment Variables** سیکشن میں مندرجہ بالا متغیرات درج کریں۔
4. **Deploy** پر کلک کریں۔ چند ہی لمحوں میں آپ کی ویب سائٹ لائیو ہو جائے گی۔
